# 大同快速選課助手（Chrome 擴充）

搭配[大同選課助手](https://github.com/shuili1013/ttucs)：把排好的課號匯入，設定日期時間，
**時間一到自動在大同「快速選課」送出**（伺服器校時 + 只在「未開放」時有限次重試）。

> ⚠️ 僅送出你自己排定的課、用你自己帳號，後果自負。採「準時送出＋失敗有限重試」，
> 請勿改成無限狂洗——那違反校規、易被鎖 IP/帳號，且會拖慢大家（含你）。

## 安裝（開發者模式載入）

1. Chrome 開 `chrome://extensions`
2. 右上開「開發人員模式」
3. 「載入未封裝項目」→ 選這個 `extension/` 資料夾
4. 釘選工具列圖示即可使用

## 使用

1. **先登入** <https://cousel.ttu.edu.tw>（保持登入，擴充會用你的 session）
2. 點擴充圖示：
   - 貼上**課號清單**（一行一個，可從網站「匯出」複製）
   - 選**排定送出時間**
   - （可選）調整重試間隔/上限
   - 按**排程**
3. 到時間，擴充會自動開/用 cousel 分頁，於**送出時刻**POST 送出（每 5 門一批）。
4. 想先驗證，可按**立即送出一次（測試）**看回應。

## 運作原理

- 送出＝`POST /main/FastSelect.php`，body `EnterSbj=課號(換行)`（表單無 CSRF token）。
- 回應含「並非您可以選課的期間」＝尚未開放 → 依設定間隔重試，達上限即停。
- 其他回應＝已開放並送出 → 停止重試（避免狂洗）。
- 校時：讀 cousel 回應的 `Date` header，用伺服器時間為準觸發。

## 檔案

| 檔 | 說明 |
|---|---|
| `manifest.json` | MV3 設定與權限（`storage/alarms/scripting/tabs` + cousel host）|
| `popup.html/js` | 匯入、排程、狀態顯示 |
| `background.js` | 排程(alarms)、校時、注入頁面送出 |
